# `scenario_run`

Сначала вызови `get_native_change_contract(operation="scenario_run", target_ref=...)`. Restore у этого действия нет.

- `scenario_run` запускает один раз существующий включённый сценарий любого
  типа: BLOCK, LOGIC, GLOBAL и другие. Просьба владельца запустить сценарий
  или сцену и есть разрешение. Prepare читает сценарий, но не запускает его.
  Apply перечитывает тот же сценарий: другой index, изменённая конфигурация,
  выключение или удаление после prepare дают `scenario_changed` без запуска.
- Выключенный сценарий получает `scenario_inactive`: запуск выключенного
  сценария на хабе не наблюдали. `next` ведёт к `scenario_active`, но
  включение снова активирует триггеры; включай только если владелец хочет
  оставить сценарий включённым.
- `targets` перечисляет буквальные `service/set` действия BLOCK с проверенной
  привязкой к характеристикам. `targets_known=false` означает, что список
  неполон: LOGIC, GLOBAL, code, toggle/inc/dec, запуск другого сценария,
  небуквальное значение, неразрешённая привязка или непонятый узел. `effect.predicted=true` только у BLOCK с известными
  целями без условий, delay и повторов одной цели. Иначе `effect.reasons`
  называет причину, и хаб сам решает, что выполнить; проверяет ли ручной run
  условия и триггеры BLOCK, не наблюдали. Что сделал хаб, покажет
  `read_hub_log` с этим `scenario_ref`.
- Перед `scenario.run({index})` намерение сохраняется в журнале. Один change
  отправляет run не более одного раза, в том числе после рестарта. Для
  повторного запуска нужен новый change. Подтверждённый отказ остаётся
  `rejected`, подтверждённая неотправка — `not_sent`; повтор apply такого
  change ничего не отправляет. Потерянный ACK означает `unknown` и не
  повторяется: совпавшие значения целей не доказывают прошлую доставку.
- Результат показывает ACK и свежее значение каждой цели отдельно. ACK не
  доказывает физическое исполнение и атомарность. При
  `effect.predicted=false` расхождение с действием не считается сбоем:
  `verification.result` равен `command_acknowledged_effect_not_predicted`.
  Физический эффект запуска не откатывается.
