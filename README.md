# sprut-agent

Инструменты для ИИ-агента, который настраивает и отлаживает умный дом на SprutHub.
Сценарии исполняются самим хабом. CLI, MCP и приложения используют общую интеграцию.

Сейчас здесь исследовательские инструменты протокола. Рабочего подключения агента
к дому пока нет. Правила разработки — в [AGENTS.md](AGENTS.md), команды — в
[package.json](package.json).

## Начать

Node.js 24 и npm:

```sh
npm ci
npm run check
npm run test:mutations
```

Git hooks проверяют Conventional Commits при коммите и `npm run check` перед push.
Промежуточные RED-коммиты разрешены; отправлять нужно зелёную голову ветки.
CI выполняет проверки и мутации без подключения к дому.

## Ближайший сквозной результат

Агент через один MCP-инструмент видит реальные устройства выбранной комнаты,
значения с единицами и временем наблюдения. После изменения датчика повторное
чтение показывает новое значение. Отключение хаба возвращает явную ошибку или
устаревшее состояние, а не убедительные старые данные.

Начать с проверки готового `spruthub-client` на настоящем хабе, затем подключить
официальный MCP SDK. Если библиотека не поддерживает нужный контракт, исправить
конкретный пробел. Полный реверс всех RPC, собственный движок сценариев и несколько
интерфейсов сразу не являются условием первого результата.

После этого — один нативный сценарий с проверкой и откатом. Постоянный поток для
дашборда добавляется следующим сквозным срезом, когда первый уже полезен.

## Исследовательские инструменты

```sh
npm run research:diff -- --from research/snapshots/1.5.58 --to research/snapshots/1.5.58
npm run research:record -- --cdp-url http://127.0.0.1:9222
npm run research:snapshot
```

Recorder пассивно записывает CDP WebSocket events в `research/captures/raw/`.
Нужна отдельная браузерная сессия с CDP и ручная авторизация. После запуска записи
перезагрузи страницу; остановка — Ctrl-C. Raw captures могут содержать секреты:
они исключены из Git и создаются с правами `0600`. Санитайзер пока не реализован.

Снимок `1.5.58` относится к сборке 2025-09-16. На публичной сборке 2026-08-31
extractor уже не определяет build; его эвристики имён proto и каталога RPC также
нуждаются в обновлении. Номер версии интерфейса недостаточен для выбора контракта.
Локальные тесты не доказывают совместимость с текущей прошивкой хаба.

`research/archive/` содержит прежние архитектурные черновики; `research/protocol/`
— исторический журнал. Это материалы исследования, не актуальный backlog.

## Что доказывают проверки

`npm test` запускает офлайн-тесты, включая recorder как отдельный процесс с
локальным CDP-сервером. Они проверяют сохранение нужного трафика и фильтрацию
посторонних сокетов. Это не live-проверка SprutHub.

Область Stryker намеренно ограничена исправленным выбором сокета и указана в
`stryker.config.json`. При следующем изменении поведения область нужно обновить.
Результат этой проверки не описывает покрытие остальных исследовательских утилит.

Историю RED/GREEN и выполненные проверки смотри в коммитах. Схемы и снимки
генерируются инструментами; их нельзя править форматтером вручную.
