# Живое соответствие, прогон 3: окна сценариев, тип LOGIC, имена, срабатывание

2026-09-24, 16:59–17:20 UTC. Задачи: проверить на хабе включение и выключение
сценария через флажок `Active` окна опций, связь типа LOGIC со сценарием,
лимит имени комнаты на кириллице и с эмодзи, ручной запуск и срабатывание
расписания включённого BLOCK. Чтение без записи — в
[отдельной заметке](2026-09-24-live-conformance-3-read-only.md).

## Источник и полномочия

- Хаб: firmware 3.0.0, revision 20131, model 2.
- sprut-agent 0.1.44. `research/live-conformance.mjs` на `69a8631` (полный
  прогон), затем на `6aff2f9` (`--only 1,V,6,6t,7,8` и `--only 1,V,6t`)
  после исправлений самого скрипта; собранный `dist/plugin/dist/server.mjs`
  тех же коммитов.
- Правила владельца: читать всё; создавать свои объекты и сразу удалять;
  свои сценарии можно включать и запускать, если они действуют только на
  временный виртуальный аксессуар прогона; настоящие устройства и сценарии
  владельца не менять. Охрана скрипта отклоняет любую запись вне этих рамок.
- Лимит имени комнаты уточнён отдельной пробой через клиент продукта: 12
  своих комнат с префиксом прогона, каждая удалена сразу после чтения,
  остатков нет.
- Итоговый снимок каждого прогона совпал с начальным (после перехода снимка
  на каноническую форму, см. «Состояние условия»); объектов прогона не
  осталось.

## Наблюдения

| Тема | Наблюдение |
| --- | --- |
| Флажок `Active`, BLOCK | Через `window.update` включение и выключение; `scenario.get` и окно совпадают с первого чтения; ключ окна стабилен; меняется только флаг |
| Флажок `Active`, LOGIC | Окно с теми же ключами; включение и выключение через окно работают, чтения совпадают сразу |
| Тип LOGIC | Выключенный LOGIC в `logic.types` опорного сервиса не виден. Включённый: запись `{type: "<индекс сценария>", name: <имя сценария>, desc: <описание>}` (`"60"`, `"61"`). После переименования через `info.name` имя записи следует за сценарием |
| LOGIC, продукт | Созданный включённым: тип сопоставлен при создании, отмена удалила. Созданный выключенным: отмена честно отказала (`logic_type_not_visible`), объект удалила уборка прогона |
| `if` без mode/задержек/else | Хранится с `mode: EVERY`, `then_delay: 0`, `else_delay: 0`; `else` отсутствует; режим группы условий как отправлен (OR) |
| Ручной запуск | `scenario.run` выключенного BLOCK хаб подтверждает, но действий не выполняет. Включённого — выполняет (изменение через 22–26 мс) |
| Срабатывание расписания | Дневной триггер на время хаба сработал вовремя. После срабатывания хаб добавил в узел `if` поле `state: true`; `nextRun` не появился. Каноническая форма продукта не изменилась, изменение продукта осталось `applied` |
| Состояние условия | У включённого BLOCK владельца `if.state` меняется само во время прогона (`true` → `false`): это состояние исполнения, а не правка |
| Имя комнаты | Хаб хранит первые 32 символа (кириллица и латиница одинаково, считаются символы, а не байты): 31 и 32 — целиком, 33–45 — обрезано до 32; ответ `room.create` уже содержит обрезанное имя. Эмодзи хаб удаляет. Во втором прогоне число 30 было выведено неверно |
| Виртуальная лампа | При яркости 0 хаб не включает лампу; запись яркости 0 в выключенную лампу игнорирует |
| Дубль виртуальной группы | Подготовка `virtual_light_group` с именем и комнатой существующего виртуального аксессуара — конфликт `matching_virtual_accessory_exists`, запись не отправлена |
| Прямая запись `Active` через `window_option` | Продукт отказывает (`scenario_owner_required`) и направляет к `scenario_active` |
| Чтение | `home_overview` 77 мс, 4402 байта; `find_devices {kind: light, state: on}` 85 мс, 15313 байт, предложена следующая страница |

## Выводы и границы

- Связь типа LOGIC со сценарием точная: тип — строка индекса сценария. Не
  проверено, видны ли назначения выключенного LOGIC в `logic.list`: в этом
  прогоне назначение не выполнялось.
- Лимит имени комнаты — 32 символа; для аксессуаров и сервисов не проверялся.
  Какие ещё символы, кроме эмодзи, хаб удаляет — не проверялось.
- `window.update {Active}` подтверждён для BLOCK и LOGIC; для GLOBAL и
  встроенных сценариев только прочитан, не записывался.
- Один хаб, одна прошивка, без повторов.
