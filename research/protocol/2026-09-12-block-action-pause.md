# Нативное условие срока для действия BLOCK, 2026-09-12

Источник: адресные опыты на SprutHub `3.0.0b (20131)`. Использовались только
временные BLOCK с log-действиями; после опытов они удалены. Устройства и
существующие правила не изменялись.

Проверенная форма:

```json
{"type":"if","mode":"EVERY","if":{"type":"condition","mode":"AND","conditions":[{"type":"code","code":"return Date.now() >= 1789183082509;"}]},"then":[...],"else":[],"then_delay":0,"else_delay":0}
```

- Без `return` Nashorn вернул native `error=true`: `Undefined` нельзя привести к
  Boolean. С `return` условие было `false` до абсолютного срока и `true` после,
  `error=false`.
- Между вычислениями управляющие клиенты были закрыты. Отложенная log-команда
  исполнилась хабом. Повторная загрузка того же source после срока сразу дала
  `true`; новое окно не началось.
- Обновление `data` отменило уже запущенную задержку прежней версии BLOCK:
  delay 3 секунды, update примерно через 0,4 секунды, старая log-команда не
  пришла. Новый явный запуск обновлённого source дал одну новую log-команду.

Это наблюдение подтверждает исполнение абсолютного code-condition и отмену
старой задержки при update на указанной версии. Полный перезапуск хаба,
физическое устройство и произвольный JavaScript не проверялись.
